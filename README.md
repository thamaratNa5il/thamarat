# موقع ثمرات للاستثمار والتنمية الزراعية

موقع ثابت (HTML) جاهز للنشر على GitHub Pages.

## الملفات
- `index.html` — الموقع كامل (كل الصفحات في ملف واحد، والتنقل بالروابط `#about` و`#order`…)
- `assets/` — اللوجو والصور وأيقونة الموقع وصورة المشاركة
- `.nojekyll` — لازم يفضل موجود علشان GitHub Pages يعرض الملفات زي ما هي

## رقم واتساب الطلبات
موجود في `index.html` في السطر اللي فيه `const WA='201274577688'`.
لتغييره: اكتب الرقم بصيغة دولية من غير + ولا صفر في الأول (مثال: 2010xxxxxxxx).

## ربط الدومين thamarat.com (اختياري)
1. من إعدادات المستودع ← Pages ← Custom domain اكتب `thamarat.com` واحفظ.
2. عند شركة الدومين ضيف سجلات A للعناوين:
   185.199.108.153 · 185.199.109.153 · 185.199.110.153 · 185.199.111.153
   وسجل CNAME لـ `www` يشاور على `thamaratna5il.github.io`
3. فعّل Enforce HTTPS بعد ما الشهادة تتفعل.
